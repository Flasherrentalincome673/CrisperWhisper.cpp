## ❓ Frequently Asked Questions

**Does this software send my audio to the internet?**
No. Everything happens on your local machine. No data leaves your computer during the transcription process.

**Can I transcribe long files?**
Yes. Use the long-form transcription setting for files lasting longer than one hour. This mode maintains focus throughout the entire recording.

**What do I do if the program closes unexpectedly?**
Check if your graphics card drivers are current. Sometimes outdated drivers cause stability issues with intensive software. Restarting your computer often fixes temporary conflicts.

**Does it support multiple speakers?**
The software detects changes in voice patterns. It organizes the output by identifying when the speaker switches during a conversation.

## 📂 Understanding Output Formats

The program saves text in clean text format. This provides compatibility with every word processor or text editor. If you want to keep timing information, use the "Subtitles" option in the export menu. This creates a file that works with video players.

## 🔍 Fine-tuning Transcription

If specific words appear incorrectly, check your microphone quality. Distant microphones or background noise reduce word accuracy. Use high-quality audio files for the best results. The software treats silence as a pause, so do not worry about gaps in your audio files.
